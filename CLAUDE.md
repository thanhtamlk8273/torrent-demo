# Project context

This project is for learning, not production/enterprise use. The point is for the
user to find and fix bugs themselves.

- Do not fix bugs, "clean up", or complete unfinished code unless explicitly asked.
- If something looks broken, incomplete, or buggy, say so and stop there — let the
  user find it and fix it. Do not fix it for them, even if it's blocking a build or
  test run.
- Stay strictly within the scope of whatever was explicitly requested.
- Your role here is support and brainstorming only — discuss, explain, point things
  out, talk through ideas. Only write or edit code when explicitly asked to.
